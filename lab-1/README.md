# ЛАБОРАТОРНАЯ РАБОТА 1: ОСНОВЫ C++ — ОДНА ПРОГРАММА НА ДИНАМИЧЕСКИХ СТРУКТУРАХ ДАННЫХ
# Требования
* Язык: C++ 20
* Система сборки: CMake 3.16+
* Тестирование: Google Test. Не менее 10 тестов Google Test. Тесты test_variant.cpp (пример для семейства A): проверьте создание/удаление массива, вставку в середину, удаление, бинарный поиск, а затем алгоритм варианта на контрольном примере.
* Вся логика оформляется как библиотека чистых функций: функции не вводят и не выводят данные сами, а принимают их параметрами, изменяют переданные структуры (в том числе по ссылке через out-параметры) и возвращают результат.
* Запрещены: классы, конструкторы, семантика копирования/перемещения, std::string, std::vector, std::array и умные указатели. Работа с памятью — только вручную (new[] / delete[]), строки — только C-строки (char*, завершающий '\0').

#### Обязательства программы (одинаковы для всех вариантов):
* Никаких утечек памяти: каждая созданная через new[] структура освобождается через delete[]. После удаления указатель обнуляется (delete[] arr; arr = nullptr;).
* Корректный ввод: при вводе чисел и меню проверяйте успешность std::cin (if (!(std::cin >> n)) { std::cin.clear(); ... }), не давайте программе упасть.
* Устойчивость к пустой структуре: функции поиска и алгоритмы должны корректно работать с массивом длины 0 (возвращать false/безопасное значение), программа не должна падать.
* Каждая операция выводит понятный результат (сам массив, длину, найденные значения).

# Задание
Семейство A — линейный динамический массив (варианты 1–8).  
Базовые операции в array_ops.h / array_ops.cpp:
```c++
// array_ops.h
#pragma once
#include <cstddef>
int* array_create(std::size_t size); // new int[size], +1 слот под '\0' не нужен
void array_delete(int*& arr); // delete[] и обнулить указатель
int* array_resize(int* arr, std::size_t size, std::size_t new_size); // новая память + копия
int* array_insert(int* arr, std::size_t& size, std::size_t pos, int value); // вставка
int* array_remove(int* arr, std::size_t& size, std::size_t pos); // удаление
void array_print(const int* arr, std::size_t size);
// Ваш вариант задания, например:
bool array_binary_search(const int* arr, std::size_t size, int target, std::size_t& out_index);
```
